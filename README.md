## Состав репозитория

| Путь | Что это |
|---|---|
| `index.html` … `privacy.html`, `404.html` | 9 страниц сайта и страница 404 |
| `css/style.css` | стили |
| `js/analytics.js` | все события GA4 (единственный файл с `gtag('event', …)`) |

| `js/calculator.js` | калькулятор стоимости кухни |

| `apps-script/Code.gs` | приёмник заявок (веб-приложение Apps Script) |
| `img/`, `files/` | изображения и PDF |
| `docs/` | запросы к нейросети, таблица событий, реестр ссылок, источники изображений, аналитическая записка, QR и афиша |
| `screens/` | снимки проверок GA4, UTM, Instagram, отчётов, исследований, DataLens, Lighthouse |

Не получилось: Instagram и ManyChat, публикации блогеров, ВКонтакте и YouTube, дашборд DataLens — не выполнялись по согласованию с преподавателем из-за срока сдачи. Из раздела 8 сделаны отчёты (`screens/reports/`), свободная форма и воронка (`screens/explore/`), аналитическая записка `docs/report.md`; не сделаны сравнения, выгрузка CSV, коллекция в Library, исследования «Путь» и «Обратный путь», Custom insight. Источник telegram / social подтверждён в отчёте «Привлечение трафика» (`screens/utm/traffic-acquisition.png`).

Нейросеть использовалась для: генерации кода страниц, стилей и скриптов, приёмника Apps Script, иллюстраций и PDF, черновиков `docs/events.md` и `docs/utm.csv`; помощи с настройкой GA4, приёмника Apps Script и реестра UTM; черновика поста для Telegram (текст поста переписан вручную).
